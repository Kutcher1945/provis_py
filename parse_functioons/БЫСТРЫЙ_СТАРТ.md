## ❓ Частые вопросы

**Q: Какие файлы поддерживаются?**
A: Только `.docx` (не `.doc`)

**Q: Можно импортировать несколько файлов сразу?**
A: Да! Используйте `python3 scripts/bulk_import.py` для массового импорта.

A: Нет! Скрипт покажет список всех организаций.

## 🔄 Массовый импорт

### Как работает массовый импорт?

```bash
python3 scripts/bulk_import.py
```

**Шаг 1: Выбор файлов**

Вам покажут список всех документов:
```
ДОСТУПНЫЕ ДОКУМЕНТЫ
================================================================================
#    Файл
--------------------------------------------------------------------------------
1    Положение УАиГ.docx
2    Положение УВП 2025.docx
3    Положение УГА.docx
...
25   Положение УЭиФ.docx
```

**Варианты выбора:**
- `1,3,5` - выбрать файлы 1, 3 и 5
- `1-5` - выбрать файлы с 1 по 5
- `1,3,5-8,10` - комбинация
- `all` - все файлы
- `архитектур` - поиск по названию

**Шаг 2: Режим импорта**

Выберите режим:
1. **Одна организация для всех** - выбрать одну ГУ, импортировать все файлы туда
2. **Для каждого файла отдельно** - для каждого файла выбрать свою ГУ

**Шаг 3: Импорт**

Скрипт автоматически:
- ✅ Парсит каждый документ
- ✅ Показывает прогресс
- ✅ Импортирует в API
- ✅ Создает итоговый отчет

**Пример вывода:**
```

--------------------------------------------------------------------------------
  📄 Парсинг документа...
    ✓ Общие положения: 2919 символов
    ✓ Задачи: 3 элементов
    ✓ Функции: 27 элементов
  🚀 Отправка в API...
  ✓ УСПЕХ! ID записи: 6750

[2/5] Обработка: Положение УВП 2025.docx
...

**Итоговый отчет:**

В конце получите отчет:
```

✓ Успешно: 5

Отчет также сохраняется в файл `data/import_report_YYYYMMDD_HHMMSS.txt`

## 📊 Типы документов

Парсер автоматически определяет 3 типа:

1. **CHAPTER-BASED** - с главами (Глава 1, 2, 3...)
   - Примеры: УАиГ, УДР, УМП

2. **NUMBERED-SECTIONS** - с нумерованными разделами (1. 2. 3...)
   - Примеры: УВП, УГК, Аппарат акима

3. **CUSTOM** - произвольная структура
   - Примеры: УГА, УК

**Вам не нужно ничего делать** - парсер определит тип автоматически!

## 🤖 Автоматическое определение организации

Режим 3 (`bulk_import.py`) автоматически определяет организацию для каждого файла:

**Как это работает:**
1. Читает начало документа
2. Извлекает полное название организации из текста (например, из «Управление земельных отношений города Алматы»)
3. Ищет точное совпадение в списке всех 36 организаций
4. Если найдено - автоматически выбирает организацию
5. Если не найдено - предлагает выбрать вручную

**Пример:**
```
✓ Положение УЗСП.docx
  → Извлечено из документа: Управление земельных отношений города Алматы
  → Найдено в системе: КГУ "Управление земельных отношений..." (ID: 12345)
```

**Преимущества:**
- ✅ Не нужно знать аббревиатуры
- ✅ Работает даже с новыми документами
- ✅ 100% точность, так как берет название напрямую из документа
