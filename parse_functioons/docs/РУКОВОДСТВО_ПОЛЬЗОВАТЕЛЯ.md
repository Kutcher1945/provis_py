## Обзор

Это приложение предназначено для автоматического импорта документов "Положение" государственных учреждений города Алматы в систему planning.gov.kz через API.

### ✨ Возможности:

- ✅ **Автоматический парсинг** документов Word (.docx)
- ✅ **Умное распознавание структуры** документа
- ✅ **Интерактивный выбор** организации для импорта
- ✅ **Поддержка 3 типов** структур документов
- ✅ **Импорт всех разделов**: Задачи, Полномочия, Функции
- ✅ **Разделение права и обязанности** автоматически

### 📋 Поддерживаемые типы документов:

1. **С главами** (Глава 1, Глава 2...) - 11 документов
2. **С нумерованными разделами** (1. Общие положения, 2. Задачи...) - 8 документов
3. **Произвольная структура** - 4 документа

## Установка и настройка

### 1. Требования

- Python 3.6 или выше
- Библиотеки: `python-docx`, `requests`

### 2. Установка библиотек

```bash
pip install python-docx requests
```

### 3. Настройка учетных данных

Отредактируйте файл `config.py`:

```python
IIN = "ваш_ИИН_здесь"
PASSWORD = "ваш_пароль_здесь"
```

⚠️ **Важно:** Не делитесь этим файлом с другими!

## Быстрый старт

### Вариант 1: Импорт документа по умолчанию (УАиГ)

```bash
python3 scripts/import_from_docx.py
```

### Вариант 2: Импорт конкретного документа

```bash
python3 scripts/import_from_docx.py "Положение УВП 2025.docx"
```

### Процесс импорта:

1. **Авторизация** - система автоматически войдет в аккаунт
2. **Выбор организации** - вам покажут список всех ГУ
3. **Парсинг документа** - автоматическое извлечение данных
4. **Предварительный просмотр** - проверка извлеченных данных
5. **Импорт** - отправка в API
6. **Результат** - ссылка на созданную запись


### 🔄 Массовый импорт документов

Импортирует любое количество документов за один запуск:

```bash
python3 scripts/bulk_import.py
```

**Возможности:**
- ✅ Выбор нужных файлов из списка (по номерам, диапазону или поиску)
- ✅ Импорт от 1 до 25+ документов сразу
- ✅ Два режима: одна организация для всех или отдельная для каждого
- ✅ Прогресс в реальном времени
- ✅ Итоговый отчет с результатами
- ✅ Сохранение отчета в файл

**Выбор файлов:**
- `1,3,5` - выбрать конкретные файлы
- `1-10` - выбрать диапазон
- `all` - все доступные файлы
- `архитектур` - поиск по названию

### Типичные проблемы и решения

#### ❌ Ошибка: "File not found"

**Причина:** Файл не находится в папке `data/`

**Решение:**
```bash
ls data/  # Проверьте содержимое
cp "ваш_файл.docx" data/
```

#### ❌ Ошибка: "Login failed"

**Причина:** Неверные учетные данные в `config.py`

**Решение:** Проверьте IIN и PASSWORD

#### ❌ Ошибка: "File is not a zip file"

**Причина:** Файл имеет расширение .doc (не .docx)

**Решение:** Откройте в Word и сохраните как .docx

```
      второй абзац (БЕЗ нумерации!)
    2) обязанности:
      первый абзац (БЕЗ нумерации!)
      второй абзац (БЕЗ нумерации!)

  16. Функции:
    1) первая функция
    2) вторая функция

3. Статус, полномочия первого руководителя
  ...
```

⚠️ **Важно:** В документах типа 2, права и обязанности НЕ нумеруются!

### Тип 3: Произвольная структура (CUSTOM)

**Примеры:** УГА, УК, УКИЖИ...

Требует дополнительной проверки после импорта.

## Часто задаваемые вопросы

### ❓ Какие форматы файлов поддерживаются?

✅ `.docx` (Word 2007+)
❌ `.doc` (старый формат Word - нужно конвертировать в .docx)
❌ `.pdf` (не поддерживается)

### ❓ Можно ли импортировать несколько документов сразу?

Пока нет. Запускайте скрипт для каждого документа отдельно:

```bash
python3 scripts/import_from_docx.py "документ1.docx"
python3 scripts/import_from_docx.py "документ2.docx"
python3 scripts/import_from_docx.py "документ3.docx"
```

### ❓ Как проверить, что импорт прошел успешно?

1. Скрипт покажет ссылку на запись:
   ```
   https://planning.gov.kz/rgffront#/rgffront/filter/positions/department/6745/edit
   ```

2. Откройте эту ссылку в браузере

3. Проверьте, что все разделы заполнены:
   - Общие положения
   - Задачи
   - Полномочия (права и обязанности)
   - Функции
   - Дополнения

### ❓ Что делать, если парсер неправильно распознал структуру?

1. Запустите анализ документа:
   ```bash
   python3 scripts/analyze_docx_structure.py
   ```

2. Проверьте тип структуры в выводе

3. Если тип определен как CUSTOM - возможно потребуется ручная корректировка после импорта

### ❓ Можно ли отменить импорт после отправки?

Да, но только через веб-интерфейс planning.gov.kz. Скрипт не предоставляет функцию удаления.

### ❓ Где хранятся учетные данные?

В файле `config.py`. **Никогда не загружайте этот файл в Git или другие публичные места!**

### ❓ Нужно ли вручную выбирать guId?

Нет! Скрипт автоматически показывает список всех организаций и позволяет выбрать нужную.

### ❓ Что означает "Detected structure: CHAPTER-BASED"?

Это означает, что парсер автоматически определил тип структуры документа:
- **CHAPTER-BASED** - с главами (Глава 1, 2, 3...)
- **NUMBERED-SECTIONS** - с нумерованными разделами (1. 2. 3...)
- **CUSTOM** - произвольная структура

### ❓ Почему в некоторых документах права и обязанности не нумеруются?

Это особенность документов типа NUMBERED-SECTIONS. В них права и обязанности идут обычными абзацами, без нумерации. Парсер учитывает это и собирает их правильно.
